D. PERSISTENT SYNOPSIS CACHE
==================================================
Persist synopsis for ALL Personal Catalog categories, not only Watched:
- Watched
- Movies
- Manhua
- Dropped / Unfinished
- New Seasons 2026
- Needs Classification

For a Personal Work with a trusted MAL/Jikan association:
- Fetch original synopsis once.
- Persist synopsis_original.
- Persist synopsis_source.
- Persist synopsis_source_language.
- Persist synopsis_fetched_at.
- Translate to Portuguese (Brazil) once through a TranslationService abstraction.
- Persist synopsis_pt_br.
- Future Anime Details reads must use Supabase/cache first.
- Do NOT translate again if both original and PT-BR already exist.

Items without a compatible source:
- Never invent synopsis.
- Persist/report status missing_source.

Backfill:
- Manual/controlled action.
- No hundreds of simultaneous requests.
- Small sequential/batched workload with rate-limit awareness.
- Per-item failure does not abort the entire run.
- Visible progress: processed/total, success, missing source, failed, current work.
- Resume naturally by skipping already completed records.
