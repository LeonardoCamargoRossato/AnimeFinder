ANIMEFINDER — PERSONAL CATALOG + AI PERSONAL KNOWLEDGE V2

Upgrade the CURRENT AnimeFinder implementation incrementally. Do NOT rebuild the app, do NOT rebuild AI Personal Knowledge, and do NOT remove working features.

PRESERVE
- Personal Catalog / My Watched Anime
- Add Anime
- Edit Ranking + drag-and-drop
- Save Changes / Cancel Changes
- Comments and Original Observations
- AI Personal Knowledge and comment versioning
- AI text organization, keyword extraction, character identification and character enrichment
- Related Works, Franchise Average, Franchise Map
- Anime Details / Deep Analysis
- Supabase/Auth
- current performance architecture

1. ENGLISH UI STANDARD
- Interface, buttons, labels, assistant messages, actions, status, tooltips, errors and confirmations must be English.
- Personal user content may remain in the user's original language, normally Portuguese.
- Never auto-translate personal comments.
- Structured keywords must be in English even when the source comment is Portuguese.

2. AI PERSONAL KNOWLEDGE — CHARACTER RANKING
- Add explicit character rank/order.
- Show drag handle and rank, e.g. ≡ #1 Osamu Mikumo.
- Reordering must be instant/local with zero server calls during drag.
- Persist only when Save characters is pressed.
- Persist order across close/reopen, refresh and login.
- Keep comments and keywords per character.
- Do not add external character APIs, photos, biographies or voice actors.

3. WATCHED / WANT TO WATCH RULE
- If the current work is already Watched, Watched remains confirmed/locked.
- Want to Watch must also be disabled/locked because a watched anime cannot be added to the future-watch wishlist.
- If not watched, both actions remain available.

4. ANIME DETAILS — MY PERSONAL KNOWLEDGE
- Add a compact MY PERSONAL KNOWLEDGE section after Related Works / Franchise Map.
- It must be lazy: initial state only displays description + Load Personal Knowledge.
- Do not fetch/render the full private knowledge before the click.
- After loading show:
  - current approved personal comment and version count
  - confirmed keywords ranked by importance
  - confirmed/highlighted characters ranked by personal order
  - short character personal-comment summary when available
  - button: Open AI Personal Knowledge
- Anime Details is a read-only summary; AI Personal Knowledge remains the editor.

5. MY WATCHED ANIME TABLE
Use this primary order:
- My Ranked
- Poster
- Anime
- MAL Score
- Original Observations
- Comments
- Characters
- Keywords
- Genres
- Full English Name
- Original Full Name
- MyAnimeList
- Knowledge

Characters:
- confirmed Personal Knowledge characters only
- respect personal character ranking
- compact chips
- show a few and +N for the remainder

Keywords:
- confirmed Personal Knowledge keywords only
- respect keyword ranking
- English labels
- compact chips

Genres:
- external provider/MAL metadata only
- never generated by AI
- max first 3 genres

Knowledge:
- compact action such as ✨ Enrich / ✓ Knowledge
- opens AI Personal Knowledge for that work

PERFORMANCE:
- never do N rows × several requests.
- Personal Knowledge summaries should use persisted/local cache and batch reads.
- Genres should reuse provider cache and load lazily for visible rows.
- keep request dedupe and existing concurrency limits.

6. ADD ANIME — SMART INITIAL RANK
- Add Initial rank after selecting an anime.
- It is only a temporary insertion position.
- If rank=20, insert the temporary row near #20 immediately and visually renumber the watched list.
- The user may continue drag-and-drop from there.
- Nothing becomes definitive until Save Changes.
- If Initial rank is omitted, append temporarily to the end.

7. CLASSIFY LATER
- Add a clear Classify later option.
- If selected, category becomes Needs Classification.
- Do not assign My Ranked.
- Do not set watched=true.
- Do not force Personal Knowledge.

8. OPTIONAL PERSONAL KNOWLEDGE DURING ADD
- Offer optional Open AI Personal Knowledge after adding.
- Adding the work must never be blocked by the knowledge workflow.

9. PERSONAL CATALOG TAB ORDER
1. Watched
2. Movies
3. Manhua
4. Needs Classification
5. Dropped / Unfinished
6. New Seasons 2026

Keep existing category semantics. Only Watched implies watched under the established catalog rules. Needs Classification, Dropped / Unfinished and New Seasons 2026 must not imply watched.

10. SUPABASE
- Extend V1 Personal Knowledge persistence with character rank/order.
- Preserve all existing comments, versions, keywords and characters.
- Keep RLS and authorized-user restrictions.
- Make the migration additive/backward-compatible.

11. WORLD TRIGGER REGRESSION TEST
Verify:
- existing comment/version history remains
- existing keywords remain
- existing characters remain
- characters can be reordered (e.g. Osamu, Hyuse, Soya, Yuichi, Yuma), saved, closed and reopened in the exact order
- UI and assistant text are English
- personal comment may stay Portuguese
- keywords are English
- World Trigger is Watched and Want to Watch is disabled
- My Personal Knowledge starts unloaded, then shows comment/keywords/characters after Load
- watched table shows Comments/Characters/Keywords/Genres/Knowledge without becoming slow
- Add Anime with Initial rank=20 inserts immediately around #20 but waits for Save Changes
- Classify later goes to Needs Classification without watched or rank

12. FINAL ARCHITECTURE PRINCIPLE
Keep three layers distinct:
- EXTERNAL KNOWLEDGE: provider/MAL score, genres, titles, relations, metadata
- PERSONAL KNOWLEDGE: user's comments, keywords, characters, character ranking/comments/keywords
- PERSONAL CATALOG: watched status, personal ranking, categories, wishlist state

These layers may reference each other but must never be conflated.
