==================================================

intent.

{
  "intent": "anime_discovery",
  "readyToSearch": true,
  "query": "RPG-like fantasy anime",
  "genres": [
    "Fantasy",
    "Adventure"
  ],
  "themes": [
    "Video Game"
  ],
  "concepts": [
    "levels",
    "skills",
    "classes"
  ],
  "excludeWatched": true,
  "clarificationQuestion": null
}

Validate structured output before using it.
